App santé 🩺 Contribution sécurité

GlycoPilot

Plateforme intelligente de monitoring du diabète en temps réel : centralisation des données (glycémie, repas, activité), dashboards interactifs, alertes automatiques et assistance intelligente pour améliorer le suivi patient et la prise de décision médicale.

Backend REST Auth JWT / Session SQL Docker CI/CD GitHub Actions Monitoring & logs

Fonctionnalités livrées

  • Suivi glycémie, repas et activité physique
  • Dashboards interactifs en temps réel
  • Alertes automatiques configurables
  • Gestion multi-profils (patient, médecin, admin)
  • Historique et tendances patient
  • Assistance intelligente à la prise de décision
🛡️
Sécurité intégrée (contributions clés)

Authentification sécurisée (mots de passe hachés, JWT, protection CSRF/XSS) · Contrôle d'accès par rôles et cloisonnement des données sensibles (PII) · Chiffrement TLS en transit et au repos · Logs de sécurité et audit trail · Bonnes pratiques OWASP : validation des entrées, rate limiting, en-têtes de sécurité, durcissement du déploiement.

Application web full-stack ⚙️ Dev from scratch

Trinity

Application e-commerce full-stack développée from scratch : gestion de produits, panier, authentification sécurisée et génération de factures PDF. L'API Open Food Facts permet de récupérer automatiquement les informations nutritionnelles via scan de code-barres.

Django + DRF React + TypeScript JWT Docker Open Food Facts API Render (déploiement)

Fonctionnalités livrées

  • Catalogue produits avec scan code-barres
  • Panier d'achat persistant
  • Authentification et gestion de compte
  • Génération de factures PDF automatique
  • Tableau de bord statistiques (ventes, revenus)
  • Déploiement containerisé via Docker
🛡️
Sécurité intégrée

Authentification par tokens JWT (access + refresh), mots de passe hachés côté serveur, API REST protégée par permissions Django, CORS configuré, containerisation Docker pour isoler les services et limiter la surface d'attaque.
